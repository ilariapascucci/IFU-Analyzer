========
Features
========

Explore detailed information about IFU Analyzer's capabilities and features.

Core Features Overview
======================

**Instrument Support**

IFU Analyzer handles data from multiple telescopes and instruments.

**Advanced Analysis**

Comprehensive tools for spectroscopic analysis including Gaussian fitting, continuum subtraction, and specialized CO flux extraction.

**Interactive Visualization**

Powerful display options with multiple colormaps, color scales, and interactive controls.

**Data Handling**

Efficient handling of large spectral cubes with intelligent memory management and region-based analysis.

**Publication-Ready Output**

Export analysis results in formats suitable for publication and external analysis tools.
